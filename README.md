# Netflix Data Analysis

This is our group project for Revature Python training. We are using a Netflix dataset to analyze movies and TV shows and create graphs.

## Dataset
We downloaded the dataset from [Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows). It contains 8,807 movies and TV shows.

## Libraries
- pandas
- matplotlib

## How to Run

Install the libraries:

```bash
pip install -r requirements.txt
```

Run the program:

```bash
python main.py
```

## Our Analysis
So far, we have created two graphs:
1. Movies vs TV Shows
2. Netflix Content Added Over Time

We found that Netflix has more movies than TV shows in this dataset.
